# 🆔 Enhanced UIDAI Duplicate Risk Intelligence System

A secure, role-based Streamlit web application designed to identify and monitor potential duplicate Aadhaar enrollment risks using analytics, audit logs, and blockchain-style data integrity verification.

---

## 🚀 Features

- 🔐 Secure login with role-based access
- 📊 Interactive dashboard with real-time metrics
- 🚨 High-risk district alerts
- 🔗 Blockchain-style hash verification for data integrity
- 📜 Complete audit logging
- 🤖 AI Assistant for user support
- 🎨 User-selectable background color
- 💬 Floating chat icon for instant help
- ⚡ Optimized performance with caching

---

## 🛠️ Technology Stack

- **Frontend & App Framework:** Streamlit
- **Data Handling:** Pandas
- **Security:** Role-based filtering
- **Audit:** File-based logging
- **Integrity:** Cryptographic hashing (blockchain concept)
- **Language:** Python 3.9+
